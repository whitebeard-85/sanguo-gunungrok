# 삼국지 군웅록 복각 유광판

영걸전 · 원소전 · 손견전 · 무제전, 네 이야기를 한 게임에서 고를 수 있는 판입니다.

## 다운로드

[Releases 페이지](https://github.com/whitebeard-85/sanguo-gunungrok/releases/latest)에서 받으세요.

| 기기 | 파일 |
|---|---|
| PC (Windows 10 / 11) | `sanguo-gunungrok-1.0-windows.zip` |
| 안드로이드 (5.0 이상) | `sanguo-gunungrok-1.0-android.apk` |

## 설치

### PC

1. zip을 바탕 화면, 문서처럼 쓰기가 되는 폴더에 풉니다. `C:\Program Files` 안은 저장이 막히니 피하세요.
2. 압축을 푼 폴더에서 `삼국지 군웅록.exe`를 실행합니다.

자세한 안내는 압축을 푼 폴더의 `실행 방법.txt`와 `docs\삼국지 군웅록 가이드.html`에 있습니다.

### 안드로이드

1. APK를 받아 설치합니다. 출처를 알 수 없는 앱이라는 확인 창이 나오면 허용하세요.
2. 저장 공간이 1.7GB 이상 필요합니다. 첫 실행 때 게임 자료를 푸느라 오래 걸릴 수 있습니다.
